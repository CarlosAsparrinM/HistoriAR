## 1. INTRODUCCIÓN

La presente Política de Privacidad explica cómo la aplicación móvil **HistoriAR** recopila, utiliza, almacena, protege y, cuando corresponda, comparte los datos personales de sus usuarios.

HistoriAR es una aplicación móvil educativa desarrollada como proyecto de tesis, orientada a la exploración de monumentos históricos mediante mapas, realidad aumentada, tours, quizzes y contenido cultural interactivo.

Al utilizar HistoriAR, el usuario declara haber leído y comprendido esta Política de Privacidad. Si no está de acuerdo con sus términos, debe abstenerse de utilizar la aplicación.

## 4. DATOS PERSONALES QUE RECOPILAMOS

HistoriAR puede recopilar los siguientes datos personales y técnicos, según el uso que realice el usuario dentro de la aplicación:

### 4.1 Datos de registro y autenticación

Cuando el usuario crea una cuenta o inicia sesión, podemos recopilar:

- Nombre del usuario.
- Correo electrónico.
- Contraseña cifrada, si el registro se realiza mediante correo y contraseña.
- Foto de perfil, si el inicio de sesión se realiza mediante Google Sign-In.
- Identificador de cuenta generado por el sistema.
- Token de autenticación para mantener la sesión activa.

Cuando el usuario utiliza **Google Sign-In**, HistoriAR no accede ni almacena la contraseña de Google. Solo recibe la información básica autorizada por el usuario, como nombre, correo electrónico y foto de perfil.

### 4.2 Datos de ubicación

HistoriAR utiliza la ubicación del dispositivo para mostrar monumentos cercanos, calcular distancias y mejorar la experiencia de exploración dentro del mapa.

La aplicación puede tratar:

- Ubicación aproximada o precisa del dispositivo mientras se usa el mapa.
- Distrito desde donde el usuario comienza a usar la aplicación.
- Distancia aproximada entre el usuario y los monumentos disponibles.

La ubicación GPS se utiliza principalmente durante el uso activo de la aplicación. Sin embargo, HistoriAR almacena el **distrito inicial de uso** (seleccionado o detectado) con fines de contextualización, estadísticas generales, personalización de contenido y mejora del servicio.

HistoriAR no realiza seguimiento permanente del usuario fuera del uso activo de la aplicación.

### 4.3 Datos de uso de la aplicación

Podemos recopilar información sobre la actividad del usuario dentro de HistoriAR, como:

- Monumentos visualizados (visitas).
- Tours consultados o completados.
- Quizzes realizados.
- Puntajes obtenidos.
- Logros o avances dentro de la aplicación.
- Fecha y hora de determinadas interacciones.
- Preferencias básicas de uso.

Estos datos se utilizan para mostrar progreso, mejorar la experiencia educativa y generar estadísticas internas.

### 4.4 Datos técnicos del dispositivo

Para fines de funcionamiento, seguridad, análisis y corrección de errores, podemos recopilar:

- Modelo del dispositivo.
- Sistema operativo.
- Versión de la aplicación.
- Identificadores técnicos del dispositivo cuando sean necesarios.
- Información de errores, fallos o rendimiento.
- Datos de conexión necesarios para operar la aplicación.

## 5. PERMISOS DEL DISPOSITIVO

HistoriAR solicita permisos del dispositivo para habilitar funciones específicas.

### 5.1 Permiso de ubicación

Se solicita para:

- Mostrar la posición del usuario en el mapa.
- Calcular monumentos cercanos.
- Centrar el mapa en la ubicación actual.
- Mejorar la experiencia de exploración.

El usuario puede denegar o desactivar este permiso desde la configuración del dispositivo. Si lo hace, algunas funciones del mapa pueden verse limitadas.

### 5.2 Permiso de cámara

Se solicita para permitir el uso de funciones de realidad aumentada.

La cámara se utiliza exclusivamente para proyectar elementos digitales 3D sobre el entorno físico del usuario. HistoriAR no graba videos, no toma fotografías ni transmite datos visuales capturados por la cámara a servidores externos.

### 5.3 Permiso de internet

Se utiliza para:

- Iniciar sesión y autenticar credenciales.
- Consultar información actualizada de monumentos.
- Descargar contenido educativo.
- Cargar modelos 3D o recursos multimedia alojados en la nube.
- Sincronizar el progreso del usuario.

## 6. FINALIDADES DEL TRATAMIENTO DE DATOS

Los datos personales y técnicos recopilados se utilizan para las siguientes finalidades:

### 6.1 Funcionamiento de la aplicación

- Crear y administrar cuentas de usuario.
- Permitir el inicio de sesión mediante correo o Google Sign-In.
- Mostrar monumentos y contenido educativo.
- Habilitar mapas y funciones de ubicación.
- Ejecutar experiencias de realidad aumentada.
- Mostrar progreso, quizzes, tours y logros.

### 6.2 Personalización de la experiencia

- Recomendar contenido según el uso de la aplicación.
- Mostrar información relevante según el distrito o ubicación general.
- Adaptar la experiencia del usuario dentro del mapa y los recorridos.

### 6.3 Seguridad

- Proteger cuentas de usuario.
- Detectar accesos no autorizados.
- Prevenir abuso de la plataforma.
- Mantener la integridad del sistema.

### 6.4 Mejora del servicio

- Analizar el funcionamiento de la aplicación.
- Detectar errores técnicos o caídas del servicio.
- Mejorar la interfaz y el rendimiento de carga.
- Evaluar el impacto de las funciones educativas.

### 6.5 Analítica interna

HistoriAR puede consolidar de manera estadística el uso de la aplicación para reportes académicos del proyecto de tesis. **La aplicación no contiene publicidad ni utiliza redes publicitarias externas.**

## 7. SERVICIOS DE TERCEROS

HistoriAR utiliza servicios tecnológicos externos indispensables para operar correctamente. Entre ellos se encuentran:

- **Google Sign-In y Firebase:** Utilizados exclusivamente como pasarela de autenticación para facilitar el registro e inicio de sesión de los usuarios (no se emplean servicios adicionales de analíticas ni notificaciones push de Firebase en la nube).
- **Amazon S3 (Simple Storage Service):** Utilizado para almacenar de forma segura las imágenes oficiales de los monumentos y los modelos 3D en formato GLB.
- **MongoDB Atlas:** Servicio de base de datos en la nube donde se aloja la información operativa del sistema de forma segura.

Estos proveedores pueden tratar datos de infraestructura técnica conforme a sus propias políticas de privacidad. HistoriAR procura limitar la interacción de datos a lo estrictamente necesario para el funcionamiento del servicio.

## 8. USO POR MENORES DE EDAD

HistoriAR no está diseñada específicamente para menores de edad, aunque su contenido es apto para ellos en contextos educativos, culturales o familiares.

Si un menor de edad utiliza la aplicación, se recomienda que lo haga con la supervisión de sus padres, tutores o responsables legales.

HistoriAR no recopila intencionalmente datos de menores sin la correspondiente autorización. Si un padre o tutor considera que un menor ha registrado una cuenta sin su consentimiento, puede comunicarse con los responsables del proyecto para solicitar la eliminación de la misma.

---

## 9. CONTENIDO DEL USUARIO

HistoriAR está diseñada para que los usuarios visualicen contenido educativo, monumentos, tours, quizzes y experiencias de realidad aumentada.

Los usuarios no pueden cargar contenido propio de carácter público (como imágenes, videos, modelos 3D, textos o comentarios en foros) dentro de la aplicación. Toda interacción operativa (visitas o puntajes) queda guardada de forma privada en su perfil personal.

---

## 10. CONSERVACIÓN Y ELIMINACIÓN DE DATOS

HistoriAR conservará los datos personales del usuario mientras su cuenta permanezca activa.

Cuando el usuario decida eliminar su cuenta a través de la opción destructiva disponible en la aplicación móvil, **el backend procederá a la destrucción y anonimización de sus datos personales de forma inmediata**. Esto significa que:

- El nombre del usuario se cambiará permanentemente a "Usuario Eliminado".
- La dirección de correo electrónico se reemplazará por una cadena de texto anónima generada por el sistema.
- Se eliminarán por completo de la base de datos la contraseña cifrada, la foto de perfil (avatarUrl) y el distrito.
- Los registros históricos de la cuenta (como visitas a monumentos e intentos de cuestionarios) se mantendrán inactivos y completamente anonimizados, con el único fin de conservar la consistencia de estadísticas globales del proyecto sin poder ser rastreados de vuelta a la identidad del usuario.

---

## 11. SEGURIDAD DE LA INFORMACIÓN

HistoriAR aplica medidas de seguridad técnicas e institucionales para proteger los datos personales frente a accesos no autorizados, pérdida, uso indebido o alteración.

Entre las medidas previstas se incluyen:
- Uso de autenticación mediante tokens JWT (JSON Web Tokens).
- Almacenamiento de contraseñas de forma cifrada (hashing con bcrypt).
- Comunicación cifrada y segura mediante protocolo HTTPS.
- Validación de datos tanto en el cliente móvil como en el servidor.
- Hosting y base de datos sobre plataformas en la nube confiables (AWS y MongoDB Atlas).

Aunque HistoriAR adopta medidas razonables de protección, el usuario debe comprender que ningún sistema de transmisión o almacenamiento en internet es 100% seguro.

## 13. TRANSFERENCIA O COMPARTICIÓN DE DATOS

HistoriAR **no vende, comercializa ni transfiere** datos personales de los usuarios a terceros con fines publicitarios o comerciales.

Los datos se compartirán únicamente de ser necesario para:
- La correcta operación técnica de la infraestructura del sistema (hosting y base de datos).
- El cumplimiento de obligaciones legales y requerimientos de autoridades competentes.
- La protección de la seguridad e integridad del servicio.

---

## 14. TRANSFERENCIAS INTERNACIONALES

Al utilizar servicios tecnológicos de terceros de alta fiabilidad, como Google, MongoDB Atlas y Amazon Web Services, algunos de los datos anonimizados o técnicos recopilados pueden ser procesados o almacenados en servidores ubicados fuera del Perú. Dichos proveedores cumplen con estándares internacionales de protección de datos de primer nivel.
