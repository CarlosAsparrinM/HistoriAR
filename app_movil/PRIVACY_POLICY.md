## 1. INTRODUCCIÓN

La presente Política de Privacidad explica cómo la aplicación móvil **HistoriAR** recopila, utiliza, almacena, protege y, cuando corresponda, comparte los datos personales de sus usuarios.

HistoriAR es una aplicación móvil educativa desarrollada como proyecto de tesis, orientada a la exploración de monumentos históricos mediante mapas, realidad aumentada, tours, quizzes y contenido cultural interactivo.

Al utilizar HistoriAR, el usuario declara haber leído y comprendido esta Política de Privacidad. Si no está de acuerdo con sus términos, debe abstenerse de utilizar la aplicación.

## 4. DATOS PERSONALES QUE RECOPILAMOS

HistoriAR puede recopilar los siguientes datos personales y técnicos, según el uso que realice el usuario dentro de la aplicación:

### 4.1 Datos de registro y autenticación

Cuando el usuario crea una cuenta o inicia sesión, podemos recopilar:

- Nombre del usuario.
- Correo electrónico.
- Contraseña cifrada, si el registro se realiza mediante correo y contraseña.
- Foto de perfil, si el inicio de sesión se realiza mediante Google Sign-In.
- Identificador de cuenta generado por el sistema.
- Token de autenticación para mantener la sesión activa.

Cuando el usuario utiliza **Google Sign-In**, HistoriAR no accede ni almacena la contraseña de Google. Solo recibe la información básica autorizada por el usuario, como nombre, correo electrónico y foto de perfil.

### 4.2 Datos de ubicación

HistoriAR utiliza la ubicación del dispositivo para mostrar monumentos cercanos, calcular distancias y mejorar la experiencia de exploración dentro del mapa.

La aplicación puede tratar:

- Ubicación aproximada o precisa del dispositivo mientras se usa el mapa.
- Distrito desde donde el usuario comienza a usar la aplicación.
- Distancia aproximada entre el usuario y los monumentos disponibles.

La ubicación GPS se utiliza principalmente durante el uso activo de la aplicación. Sin embargo, HistoriAR puede almacenar el **distrito inicial de uso** con fines de contextualización, estadísticas generales, personalización de contenido y mejora del servicio.

HistoriAR no busca realizar seguimiento permanente del usuario fuera del uso de la aplicación.

### 4.3 Datos de uso de la aplicación

Podemos recopilar información sobre la actividad del usuario dentro de HistoriAR, como:

- Monumentos visualizados.
- Tours consultados o completados.
- Quizzes realizados.
- Puntajes obtenidos.
- Logros o avances dentro de la aplicación.
- Fecha y hora de determinadas interacciones.
- Preferencias básicas de uso.

Estos datos se utilizan para mostrar progreso, mejorar la experiencia educativa y generar estadísticas internas.

### 4.4 Datos técnicos del dispositivo

Para fines de funcionamiento, seguridad, análisis y corrección de errores, podemos recopilar:

- Modelo del dispositivo.
- Sistema operativo.
- Versión de la aplicación.
- Identificadores técnicos del dispositivo cuando sean necesarios.
- Información de errores, fallos o rendimiento.
- Datos de conexión necesarios para operar la aplicación.

## 5. PERMISOS DEL DISPOSITIVO

HistoriAR puede solicitar permisos del dispositivo para habilitar funciones específicas.

### 5.1 Permiso de ubicación

Se solicita para:

- Mostrar la posición del usuario en el mapa.
- Calcular monumentos cercanos.
- Centrar el mapa en la ubicación actual.
- Mejorar la experiencia de exploración.

El usuario puede denegar o desactivar este permiso desde la configuración del dispositivo. Si lo hace, algunas funciones del mapa pueden verse limitadas.

### 5.2 Permiso de cámara

Se solicita para permitir el uso de funciones de realidad aumentada.

La cámara se utiliza para mostrar elementos digitales sobre el entorno físico del usuario. HistoriAR no graba videos ni toma fotografías automáticamente desde la cámara para enviarlas al servidor.

### 5.3 Permiso de internet

Se utiliza para:

- Iniciar sesión.
- Consultar información de monumentos.
- Descargar contenido educativo.
- Cargar modelos 3D o recursos multimedia.
- Sincronizar progreso del usuario.
- Usar servicios de terceros necesarios para el funcionamiento de la aplicación.

## 6. FINALIDADES DEL TRATAMIENTO DE DATOS

Los datos personales y técnicos recopilados se utilizan para las siguientes finalidades:

### 6.1 Funcionamiento de la aplicación

- Crear y administrar cuentas de usuario.
- Permitir el inicio de sesión mediante correo o Google Sign-In.
- Mostrar monumentos y contenido educativo.
- Habilitar mapas y funciones de ubicación.
- Ejecutar experiencias de realidad aumentada.
- Mostrar progreso, quizzes, tours y logros.

### 6.2 Personalización de la experiencia

- Recomendar contenido según el uso de la aplicación.
- Mostrar información relevante según el distrito o ubicación general.
- Adaptar la experiencia del usuario dentro del mapa y los recorridos.

### 6.3 Seguridad

- Proteger cuentas de usuario.
- Detectar accesos no autorizados.
- Prevenir abuso de la plataforma.
- Mantener la integridad del sistema.

### 6.4 Mejora del servicio

- Analizar el funcionamiento de la aplicación.
- Detectar errores técnicos.
- Mejorar la interfaz y rendimiento.
- Evaluar el uso de las funciones educativas.

### 6.5 Publicidad y analítica

HistoriAR puede utilizar servicios como Firebase, Google Analytics for Firebase, Google AdMob u otros servicios similares para análisis de uso, medición de rendimiento, notificaciones, diagnóstico de errores o visualización de anuncios.

HistoriAR puede utilizar servicios tecnológicos de terceros para operar correctamente. Entre ellos pueden encontrarse:

- Google Sign-In, para autenticación.
- Firebase, para servicios técnicos, analítica, notificaciones o diagnóstico.

Estos proveedores pueden tratar datos conforme a sus propias políticas de privacidad y condiciones de servicio. HistoriAR procura utilizar proveedores confiables y limitar el tratamiento de datos a lo necesario para el funcionamiento de la aplicación.

## 8. PUBLICIDAD

HistoriAR es una aplicación gratuita. Para sostener o complementar su funcionamiento, puede mostrar anuncios mediante servicios como Google AdMob.

Los anuncios pueden basarse en información técnica, datos de uso o parámetros permitidos por la plataforma publicitaria. Cuando corresponda, el usuario podrá administrar preferencias de anuncios desde la configuración del dispositivo, su cuenta de Google o las opciones disponibles dentro de la aplicación.

HistoriAR no vende directamente datos personales de los usuarios a anunciantes.

---

## 9. USO POR MENORES DE EDAD

HistoriAR no está diseñada específicamente para menores de edad, aunque puede ser utilizada por ellos en contextos educativos, culturales o familiares.

Si un menor de edad utiliza la aplicación, se recomienda que lo haga con supervisión de sus padres, tutores o responsables legales.

HistoriAR no busca recopilar intencionalmente datos de menores sin autorización. Si un padre, madre o tutor considera que un menor ha proporcionado datos personales sin autorización, puede comunicarse con los responsables del proyecto para solicitar la revisión o eliminación de dichos datos.

---

## 10. CONTENIDO DEL USUARIO

Actualmente, HistoriAR está diseñada para que los usuarios visualicen contenido educativo, monumentos, tours, quizzes y experiencias de realidad aumentada.

Los usuarios no pueden subir contenido propio, como imágenes, videos, modelos 3D, textos o publicaciones públicas dentro de la aplicación.

## 11. CONSERVACIÓN DE DATOS

- Desactivar la cuenta.
- Eliminar datos personales asociados.
- Anonimizar datos de uso para estadísticas internas.

## 12. SEGURIDAD DE LA INFORMACIÓN

HistoriAR aplica medidas razonables de seguridad para proteger los datos personales frente a accesos no autorizados, pérdida, uso indebido o alteración.

Entre las medidas previstas se incluyen:

- Uso de autenticación mediante tokens.
- Almacenamiento de contraseñas de forma cifrada o hasheada.
- Comunicación segura mediante HTTPS en producción.
- Control de acceso a servicios administrativos.
- Validación de datos en cliente y servidor.
- Uso de servicios de infraestructura confiables.

Ningún sistema informático es completamente seguro. Por ello, aunque HistoriAR adopta medidas razonables de protección, no puede garantizar seguridad absoluta frente a incidentes externos, fallos técnicos o acciones de terceros.
